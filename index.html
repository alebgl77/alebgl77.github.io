Open-source work

1. LLM observability and FinOps on an open stack

OpenTelemetry GenAI → Prometheus → Grafana, self-hosted, on the telemetry a platform already emits.

  • grafana-llmops-forge

    Discovers what a Grafana deployment actually collects (OTel GenAI, LiteLLM, vLLM/TGI, DCGM), then generates and deploys seven dashboards for FinOps, agents, quality and governance, with multi-window burn-rate SLO alerts. CI checks queries and contracts; rendering capture and optional DOM prechecks prepare a separate, optional human or vision-agent semantic visual review.

    v2.0 · zero dependencies · E2E CI on Grafana 9.5 → 13.2 · generated queries checked against a real Prometheus in CI · listed in awesome-observability

  • openspanguard

    An OTLP enrichment gateway that evaluates completed generation spans, keeps original trace IDs and timestamps, and exposes evaluation coverage next to quality scores, so a good average cannot hide unevaluated traffic.

    developer preview · offline demo and Tempo/Alertmanager stack · project page

  • dsh-plugin-otel-genai

    Content-free OpenTelemetry GenAI token and latency metrics for DeepSeek Harness, ready for the grafana-llmops-forge dashboards.

2. Evidence-first AI governance

  • open-shadow-ai

    Self-hosted Shadow AI discovery that correlates DNS and proxy logs, Zeek/Suricata, an endpoint agent (processes, browser extensions) and Entra ID / Active Directory, with an explicit evidence level per finding: presence is never reported as usage.

    0.3 preview · 11-job CI with SBOM and signed image evidence · OIDC SSO and SCIM · EN/FR/zh-CN

  • Governance blueprint of grafana-llmops-forge

    Maps EU AI Act articles 12, 26(6), 50 and 73, ISO/IEC 42001 and NIST AI RMF to live signals: logging continuity, automatic model inventory and incident watch. An evidence layer for auditors, not legal advice.

3. Agents under control

  • ftp-deploy-mcp

    An MCP deployment server for FTP, FTPS and SFTP with local-root confinement and SFTP host-key pinning. Enabling stateDir adds the durable workflow: SHA-256-verified staged promotion, explicit MCP confirmation, resume and conservative rollback of acknowledged changes.

    npm 0.3.2 · Official MCP Registry · listed in awesome-mcp-servers · 43 scripted scenarios run in English and French against the real MCP SDK client

  • tierdecay

    A per-repo learning layer for AI coding routers. It moves a recurring task class to a cheaper tier only after statistically confirmed successes, and recertifies it when models change.

    Controlled pilot: fast tier without a playbook vs frontier at 0.657× warm-cache cost per task (95% interval 0.626–0.694; nine paired tasks). Protocol replay: 24% lower modeled cost vs always-frontier, including distillation · SBOM · OCI image · MCP server

  • claude-inc

    A Claude Code plugin that runs a project as a virtual company, with bounded review loops and SHA-256 records of submitted artifacts. The unreleased 1.6.0-dev.0 source has peer CEO, CTO and CAIO, nine departments and 64 skill manuals.

    Published v1.5.1: peer CEO/CTO, eight departments and 54 manuals · project page

  • harnessmeter

    Estimates the token footprint of instructions and skills, offline by default. The unreleased source supports Claude Code and Codex inventories, baselines and CI budgets. Optional T2 review for Claude-profile audits sends claim text and session counts through an agent CLI to its model provider, using its quota.

    Published npm 0.3.0: Claude Code session analysis and reviewable demotion patches · zero dependencies · CI on Linux, macOS and Windows

Also: generative-engine-monitor measures brand visibility in AI answers, comparing parametric and web-grounded modes with bootstrap confidence intervals. awesome-ai-architect is a self-updating map of the GenAI engineering stack, classified daily by GitHub Actions (interactive explorer).

FAQ

What does Alexandre Beguel specialize in?
Production GenAI and agentic systems. He covers the full path from scoping to operation: architecture, evaluation, observability, cost control and AI governance.
How can a team measure the cost of its LLMs?
Start from the telemetry already emitted, then attribute cost per team, model and provider. grafana-llmops-forge builds these FinOps dashboards in Grafana without a vendor SDK.
How can a company detect Shadow AI?
Correlate network, endpoint and identity signals, and keep presence separate from usage. open-shadow-ai does this self-hosted, with an evidence level per finding.
How do you prepare GenAI systems for the EU AI Act?
Build the evidence first: AI inventory, logging continuity, transparency notices and incident tracking. Article 50 transparency obligations apply since 2 August 2026. Under the AI Omnibus (Regulation (EU) 2026/1744), Annex III high-risk obligations apply from 2 December 2027.
